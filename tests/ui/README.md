# Проверка интерфейса в браузере

Эти проверки не изменяют данные приложения: они открывают основные страницы, проверяют, что сервер не возвращает ошибку 500, снимают скриншоты и ищут горизонтальное переполнение и возможные пересечения интерактивных элементов.

## 1. Установить Playwright

Из корня проекта в PowerShell:

    .\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
    .\.venv\Scripts\python.exe -m playwright install chromium

## 2. Запустить приложение

В первом окне PowerShell запустите приложение обычным для проекта способом, например:

    .\.venv\Scripts\python.exe app.py

Оставьте это окно открытым.

## 3. Запустить UI-проверки

Во втором окне PowerShell перейдите в корень проекта и укажите учётную запись, существующую в вашей локальной базе. Не вставляйте пароль в отчёты и не отправляйте его в переписке.

    $env:UI_USERNAME = "admin"
    $env:UI_PASSWORD = "ВАШ_ПАРОЛЬ"
    $env:UI_BASE_URL = "http://127.0.0.1:5000"
    .\.venv\Scripts\python.exe -m unittest discover -s tests\ui -v

Если у вас изменён пароль администратора, укажите актуальный. Пароль по умолчанию использовать только если он действительно не менялся.

## 4. Где смотреть результаты

В test-results\ui\ появятся скриншоты для пяти страниц (главная, оборудование, проекты, сотрудники, справка) на трёх ширинах: 1440, 768 и 390 пикселей. Файл layout-report.txt содержит найденное горизонтальное переполнение и возможные пересечения кнопок/ссылок.

Проверка пересечений — эвристика: наложение может быть намеренным (например, плавающий QR-виджет или крестик внутри уведомления). Такие случаи надо оценивать по скриншоту. Переносы текста, слишком маленькие отступы и визуально неудобные кнопки также лучше проверять глазами.

## 5. Как передать найденные дефекты

Пришлите layout-report.txt и ZIP-архив папки test-results\ui либо отдельные скриншоты проблемных страниц. Можно дополнительно обвести дефект на скриншоте и подписать желаемое поведение. Не нужно подробно описывать каждый пиксель: скриншоты наглядно покажут, что именно не так.

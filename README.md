# Трекер — версия 3.1.1


Современная минималистичная система учета оборудования с возможностью генерации DOCX актов приема-передачи, импортом/экспортом базы данных, редактированием операций и гибким отслеживанием истории перемещений.

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Перед первым запуском на существующей базе данных выполните миграцию: `flask --app app upgrade-schema`
3. Запустите: `python app.py` (или `./run.sh` / `run.bat`)
4. Перейдите в браузере по адресу `http://127.0.0.1:5000`

Команда `upgrade-schema` выполняет совместимые обновления старой SQLite-схемы и заполнение новых полей. Она идемпотентна и не запускается автоматически при каждом создании приложения. При первом запуске новой установки приложение создаёт таблицы через SQLAlchemy.
